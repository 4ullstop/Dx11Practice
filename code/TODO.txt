Voxel Research info:
 - Create a bounding box with dimesions (see Seen code for bounding box creation)
 - VoxelResolution = (BoundingBoxExtent * 2) / VoxelSize;
 Create a compute buffer of this resolution value and send it to the gpu
 Then instance cubes equal to our voxel count

To get the location of a box:
x = i % width;
y = (i / width) % height;
z = i / (width * height);

To get world space:
(x, y, z) * voxelResolution - BoundingBoxExtent;

Add this world position to the verts of the instanced cubes

You have to create a buffer for every single object you load into the world, except for when you are
instancing the object in which case you have one which you reference throughout the code


Throw the array into a constant buffer, use the SV_InstanceID as the index into the array that holds all of the location information
